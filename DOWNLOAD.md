# Updated dashboard preview

Download **TMV-Dashboard-Windows-Preview.zip** from this branch using the file page’s **Download raw file** button. The ZIP contains the updated application source, the Windows launcher and the audit handoff. It excludes environment files, installed dependencies and the original archive.

Install Node.js 24, extract the ZIP and double-click **start-dashboard.cmd**. Keep its terminal open. The browser opens the local dashboard after startup.

See [Windows preview instructions](WINDOWS-PREVIEW.md) for details. This preview uses synthetic sample data and does not change production operations.
