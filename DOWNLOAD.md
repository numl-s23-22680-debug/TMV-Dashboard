# TMV Aurora — updated dashboard

Download **TMV-Dashboard-Windows-Preview.zip** using the file page’s **Download raw file** button. The ZIP contains the working updated source, Windows launcher, screenshots and completed audit/brief checklists. Environment files, installed dependencies and the original archive are excluded.

Install Node.js 24, extract the ZIP and double-click **start-dashboard.cmd**. Keep the terminal open. The browser opens the sample week after both services are ready. Use the header theme selector for Light, Midnight or System. Production operations are disabled in this isolated preview.
